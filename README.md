# fake-hundouluo

一款基于 HTML5 Canvas 的模仿魂斗罗风格射击游戏，支持单人模式和双人联机对战模式。

## 游戏特性

- 多种武器类型：散弹枪(S)、追踪导弹(K)、螺旋弹(F)、闪电(T)、普通(R)
- 多样化敌人：步兵、伞兵、喷火兵、定点炮台、大型精英敌人
- 丰富的场景：陆地关卡、水路关卡、移动平台
- 水路 Boss 战：机械飞鱼 Boss，多阶段战斗
- 水中系统：可潜水躲避子弹，水中移动速度减缓
- 简易模式：输入 `xxx` 开启飞行模式（单人模式下可用）
- 双人联机对战：通过 WebSocket 实时匹配，支持再来一局和胜率统计
- 电子音乐 BGM 及独立音量控制
- 移动端触屏支持

## 操作说明

| 按键 | 功能 |
|------|------|
| ← → | 移动 |
| ↑ | 瞄准上方 |
| ↓ | 趴下 / 水中潜水 |
| K / SPACE | 跳跃 |
| X / J | 射击 |
| R | 切换子弹类型 |
| P | 暂停 |

## 快速开始

### 单人模式

1. 双击 `启动服务器.bat`，或在终端运行：

   ```bash
   npm start
   ```

2. 浏览器打开 `http://localhost:3000`

3. 点击「单人游戏」开始

### 双人联机对战

1. 主机启动服务器后，终端会显示公网地址（需安装 localtunnel）

2. 将公网地址发送给对手

3. 双方在游戏页面点击「双人对战」，输入服务器地址后等待匹配

4. 双方确认就绪后自动倒计时开始

## 依赖安装

```bash
npm install
```

## 联网方案

双人对战需要公网可访问的地址，支持以下方式：

- **localtunnel**（推荐，无需注册）：`npm install localtunnel`，启动服务器后自动获取公网地址
- **ngrok**：另开终端运行 `ngrok http 3000`
- **局域网**：同一网络下直接使用本机 IP 访问

## 技术栈

- HTML5 Canvas 游戏渲染
- Web Audio API 音效与音乐
- Node.js + WebSocket (ws) 实时对战服务
- localtunnel 内网穿透
